# Сладкая витрина

Telegram-бот: каталог домашней кондитерской с оформлением заявок.

## Для клиента
- Каталог по категориям: карточки товаров с фото, описанием и ценой
- Листание карточек кнопками ⬅️ ➡️ без «прыжков» чата
- Заявка: имя, телефон (кнопкой «Поделиться номером» или вручную), комментарий
- «Мои заявки» (`/myorders`): просмотр и отмена своих заявок

## Для владельца (`/admin`)
- Уведомления о новых и отменённых заявках
- Список заявок: отметить выполненной или отменить с уведомлением клиенту
- Добавление товаров с фото прямо через бота
- Замена фото и удаление товаров

## Технологии
Python 3.12, aiogram 3 (FSM, inline и reply-клавиатуры), SQLite

## Запуск
1. `pip install -r requirements.txt`
2. Скопировать `.env.example` в `.env` и заполнить:
   - `BOT_TOKEN` — токен от @BotFather
   - `ADMIN_ID` — Telegram ID владельца (можно узнать командой `/myid`)
3. `python main.py`
